# プロダクトビジョン

AI Office は、人間が定義した業務フローを AI が担当工程ごとに処理できる汎用基盤である。人間は業務の目的、工程順序、担当者、承認点を明示し、システムはその定義を忠実に実行・記録する。

## 提供する価値

- テキストで定義した社員と仕事を追加・変更できる。
- 共通エンジンが状態遷移、入力検証、再試行、成果物保存を一貫して扱う。
- 実行に使った定義・入力・プロンプト・生応答・成果物・イベントを追跡できる。
- 仕様を GitHub Issue で管理し、AI が再現可能な開発作業を行える。

## 守る原則

- ワークフロー順序は人間が定義する。
- AI は割り当てられた工程だけを処理する。
- 定義にない工程、分岐、補完は行わない。
- 不正な定義は実行開始前に失敗させる。
- 人間承認が必要な操作では、明示的に停止する。

## 非目標

この段階では、特定の業務領域向けの仕様、AI 工程の実行、条件分岐、並列実行、承認画面、GUI、外部エージェント連携を提供しない。
